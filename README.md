# SSAFY 성격 검사

SSAFY 캐릭터 4개(스타티, 알지, 핏, 와이즈)에 맞는 성격 검사 페이지입니다.

## 기능

- 인트로 페이지: 검사 시작하기 버튼
- 질문 페이지: 한 문제당 한 페이지, 상단에 진행률 표시
- 결과 페이지: 선택한 답변에 따라 4가지 캐릭터 타입 중 하나 표시

## 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```

## 이미지 파일 추가

캐릭터 이미지를 사용하려면 `public/images/` 폴더에 다음 파일들을 추가해주세요:

- `starty.png` - 스타티 캐릭터
- `fit.png` - 핏 캐릭터
- `alji.png` - 알지 캐릭터
- `wise.png` - 와이즈 캐릭터

이미지가 없어도 페이지는 정상적으로 작동하며, 이미지 부분만 표시되지 않습니다.

## 캐릭터 소개

### 스타티
- 시작이 빠르고 실행력이 강함
- 추진력·적응력·팀워크 최고
- 하지만 디테일을 놓치고 성급함

### 알지
- 논리적·지적 능력 우수
- 실패 데이터를 학습 자원처럼 활용
- 에러를 두려워하지 않는 강한 멘탈

### 핏
- 팀워크 중심의 조율가
- 갈등을 조용히 정리하고 연결하는 감각 보유
- 혼자보다 함께 할 때 힘이 커지는 타입

### 와이즈
- 본질·원리를 파고드는 탐구형
- 직관적 통찰력과 구조 분석 능력이 뛰어남
- 너무 깊이 생각해 실행이 늦어질 때 있음
